# legacy-calc-2009

This project is based on the original LoanCalculatorCpp repository and is used for Software Engineering Assignment 2.

## How to Build (Console)
Use the following command in the project directory:

g++ -std=c++11 *.cpp -o calc

## How to Run
./calc -cp -a 100000 -i 12 -n 360
